- **domain:** auth
- **URL:** `http://localhost:8080/auth/login`
- **method:** `POST`
- **인증/인가:** 없음

# 1. 설명

---

이메일과 비밀번호를 이용해 로그인하는 API입니다.
- 이메일과 비밀번호는 필수 입력값입니다.
- 이메일로 유저를 조회하고 비밀번호가 일치하는지 검증합니다.
- 로그인 성공 시 사용자에게 성공 메세지를 반환합니다

# 2. 요청(Request)

---

## a. Parameter & Querystring

- 없음

## b. Request headers

| 이름         | 데이터타입 | 설명                                |
|--------------|------------|-------------------------------------|
| Content-Type | String     | 요청 데이터 형식 (application/json) |


## c. Request Body

```json
{
  "email": "sparta@naver.com",
  "pw": "12345678"
}
```

## d. Request Body 명세

| 이름  | 필수여부 | 데이터타입 | 설명                                 |
|-------|----------|------------|--------------------------------------|
| email | Y        | String     | 유저 로그인시 인증에 필요한 이메일   |
| pw    | Y        | String     | 유저 로그인시 인증에 필요한 비밀번호 |


## 3. 응답(Response)

---

## a. Response header

| 이름         | 데이터타입 | 설명                                             |
|--------------|------------|--------------------------------------------------|
| Content-Type | String     | text/plain                                       |
| Set-Cookie   | String     | 새 세션 생성 시 JSESSIONID 쿠키가 전달될 수 있음 |

## b. Response body

**성공 응답: 200 OK**

```text
로그인 성공했습니다.
```

## c. Response Body 명세

| 이름               | 데이터 타입 | 설명                             |
|--------------------|-------------|----------------------------------|
| 로그인 성공 메세지 | String      | 로그인 성공 결과를 나타내는 문자 |


## 에러 응답
**잘못된 요청: 400 Bad Request**

- 이메일 또는 비밀번호가 누락되거나 공백만 있는 경우입니다.

**로그인 실패: 401 Unauthorized**
- 이메일이 일치하지 않는 경우
```text
이메일이 일치하지 않습니다.
```
- 비밀번호가 일치하지 않는 경우
```text
비밀번호가 일치하지 않습니다.
```
